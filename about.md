<h1>About TunedInn</h1>

<p>
  <strong>TunedInn</strong> is a community-focused resource hub for Microsoft Intune, Windows Autopilot,
  and endpoint automation. Whether you're on the Help Desk troubleshooting your first enrolled laptop
  or a Senior Admin automating Graph API workflows, you're welcome here.
</p>

<h2>How Everything Connects</h2>
<ul>
  <li><strong>GitHub (<a href="https://github.com/tunedinn" target="_blank" rel="noopener">@tunedinn</a>)</strong> — Open-source PowerShell scripts, Proactive Remediations, and tools.</li>
  <li><strong>TunedInn Guides</strong> — Plain-English breakdowns explaining the <em>why</em> and <em>how</em> behind every tool.</li>
  <li><strong>YouTube Walkthroughs</strong> — Embedded video demos so you can see each solution in action before deploying it.</li>
</ul>

<h2>Repositories</h2>
<ul>
  <li><a href="https://github.com/tunedinn/intune-remediations" target="_blank" rel="noopener">tunedinn/intune-remediations</a> — Detect &amp; Remediate scripts</li>
  <li><a href="https://github.com/tunedinn/intune-scripts" target="_blank" rel="noopener">tunedinn/intune-scripts</a> — General Intune, Win32, and Graph API scripts</li>
</ul>
