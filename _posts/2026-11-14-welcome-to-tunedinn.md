Welcome to **TunedInn**!

The goal of this space is simple: build practical **Microsoft Intune scripts, Proactive Remediations, and Autopilot guides** that solve real admin problems—and explain them clearly enough for anyone from **Help Desk** to **Senior Endpoint Engineers** to use with confidence.

## What to Expect
Every tool we release follows the same workflow:
1. **Build &amp; Test** a clean PowerShell script or remediation.
2. **Publish to GitHub** in [`intune-remediations`](https://github.com/tunedinn/intune-remediations) or [`intune-scripts`](https://github.com/tunedinn/intune-scripts).
3. **Write a Guide** right here breaking down how it works and how to deploy it in Intune.
4. **Embed a YouTube Walkthrough** so you can watch it end-to-end.

*(Tip: When a post has a YouTube video, we embed it directly below using `{% raw %}{% include youtube.html id="YOUR_VIDEO_ID" %}{% endraw %}`.)*

Stay tuned—our first Intune tools and walkthroughs are up next!
